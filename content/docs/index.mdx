## C++

Create a file named `hello_world.cpp` and add the following code:

```cpp
#include <iostream>

int main() {
  std::cout << "Leave me alone, world!" << std::endl;
  return 0;
}
```

## Compilation

To compile and run the code, you can use the following command in your terminal:

```bash
g++ -o hello_world hello_world.cpp && ./hello_world
```
