---
title: Arithmetic Operators 
---

Arithmetic operators perform basic mathematical operations.

## Operators

| Operator | Meaning        | Example |
|----------|----------------|---------|
| `+`      | Addition       | `a + b` |
| `-`      | Subtraction    | `a - b` |
| `*`      | Multiplication | `a * b` |
| `/`      | Division       | `a / b` |
| `%`      | Modulo         | `a % b` |

## Example

```cpp
#include <iostream>
int main() {
  int a = 10, b = 3;

  std::cout << a + b << "\n"; // 13
  std::cout << a - b << "\n"; // 7
  std::cout << a * b << "\n"; // 30
  std::cout << a / b << "\n"; // 3
  std::cout << a % b << "\n"; // 1
}
```
