## Address-of Operator `&`

Gets memory address.

## Dereference Operator `*`

Accesses value at address.

## Example

```cpp
#include <iostream>
int main() {
  int x = 10;
  int* p = &x;

  std::cout << p << "\n";  // address
  std::cout << *p << "\n"; // value (10)
}
```
