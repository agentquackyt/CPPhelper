---
title: Relational Operators 
---

Relational operators compare values and return `true` or `false`.

| Operator | Meaning              |
|----------|----------------------|
| `==`     | Equal to             |
| `!=`     | Not equal            |
| `>`      | Greater than         |
| `<`      | Less than            |
| `>=`     | Greater or equal     |
| `<=`     | Less or equal        |

## Example

```cpp
#include <iostream>
int main() {
  int a = 5, b = 8;

  std::cout << (a < b) << "\n";  // 1 (true)
  std::cout << (a == b) << "\n"; // 0 (false)
}
```
